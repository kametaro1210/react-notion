
==========================================
npmで追加したライブラリのメモ
==========================================

このメモでは、次のコマンドで追加したライブラリの役割と、
インストール後に確認・実施する手順を説明します。

npm install react-router-dom react-icons cmdk

このプロジェクトでは、Reactアプリの「app」フォルダーに「package.json」があります。
npmコマンドは、基本的にこの「app」フォルダーで実行します。

ライブラリをインストールしただけでは、画面に機能やアイコンが自動で追加されるわけではありません。
ソースコードから必要な機能を読み込んで使い、ブラウザーやビルドで動作を確認します。

------------------------------------------
1. 追加したライブラリの役割
------------------------------------------

react-router-dom
Reactアプリの画面切り替えやURLごとの表示を管理するライブラリです。
ページを移動するときにブラウザー全体を読み込み直さず、表示する画面を切り替えられます。

主な機能:

BrowserRouter
ブラウザーのURLを使ったルーティングを有効にします。

Routes、Route
URLに応じて、表示するコンポーネントを設定します。

Link
アプリ内の別の画面へ移動するリンクを作ります。

useNavigate
ボタン操作や処理の完了後などに、コードから別の画面へ移動します。

react-icons
Reactのコンポーネントとしてアイコンを表示するライブラリです。
さまざまなアイコンセットから必要なアイコンを選んで使用できます。

アイコンは使うファイルで読み込み、コンポーネントとして配置します。
必要なアイコンだけを読み込むと、コードの意図が分かりやすくなります。

cmdk
コマンドメニューやコマンドパレットを作るためのReactコンポーネントライブラリです。
項目の検索やキーボードでの選択など、コマンドメニューに必要な操作を組み立てられます。

cmdkをインストールしただけで、コマンドパレットやショートカットが自動的に追加されるわけではありません。
アプリの画面にコンポーネントを組み込み、開閉方法や各コマンドの処理を実装します。

------------------------------------------
2. npm installを実行する場所
------------------------------------------

ターミナルで、Reactアプリの「app」フォルダーに移動します。
コマンドを実行する前に、現在の場所が「app」であることを確認してください。

例:

cd app

場所を確認する場合:

pwd

Windowsのコマンドプロンプトでは、代わりに次のコマンドで場所を確認できます。

cd

「app」フォルダーにいる状態で、次のコマンドを実行します。

npm install react-router-dom react-icons cmdk

npmは、指定したライブラリとその依存パッケージをインストールします。
通常、「app\package.json」のdependenciesにライブラリが記録され、
インストール内容を再現するための「app\package-lock.json」も更新されます。

------------------------------------------
3. インストール結果を確認する
------------------------------------------

コマンドがエラーなく終了したことを確認します。
続けて、「app\package.json」のdependenciesに次のライブラリがあることを確認します。

react-router-dom
react-icons
cmdk

このプロジェクトでは、現在のpackage.jsonに次のバージョン範囲が記録されています。

react-router-dom: ^7.18.4
react-icons: ^5.7.0
cmdk: ^1.1.1

package.jsonに記録されていれば、以後はプロジェクトのフォルダーで
npm installを実行することで、必要なパッケージをインストールできます。
チームのメンバーや別の環境で作業するときも、通常は個別に同じライブラリを追加せず、
package.jsonとpackage-lock.jsonを使ってnpm installで環境を準備します。

------------------------------------------
4. アプリでライブラリを使う
------------------------------------------

各ライブラリは、必要な機能を使うソースファイルから読み込みます。
読み込んだ後、画面や処理に組み込みます。

react-router-dom
URLと画面の対応を決め、アプリ内リンクや画面遷移を実装します。
アプリの構成に合わせて、ルーティングを設定するファイルやコンポーネントを選びます。

react-icons
使用するアイコンを読み込み、ボタンや見出しなどの必要な場所に配置します。

cmdk
コマンドメニューの表示内容、検索対象、項目を選んだときの処理を実装します。
メニューを開く操作や閉じる操作も、アプリの仕様に合わせて用意します。

ライブラリごとの具体的な実装は、使用する画面や必要な動作を決めてから行います。
不要な画面や機能が自動で生成されることはありません。

------------------------------------------
5. 起動して動作を確認する
------------------------------------------

ライブラリをソースコードに組み込んだ後、アプリを起動します。
「app」フォルダーで次のコマンドを実行します。

npm run dev

ターミナルに表示されたURLをブラウザーで開き、画面が表示されることを確認します。
追加した画面遷移、アイコン、コマンドメニューを実際に操作して確認します。

起動中にエラーが表示された場合は、エラーメッセージと読み込み先、
コンポーネントの書き方を確認して修正します。

------------------------------------------
6. lintとbuildで確認する
------------------------------------------

画面の確認後、「app」フォルダーで次のコマンドを実行します。

npm run lint
npm run build

npm run lint
ESLintでソースコードを検査します。

npm run build
TypeScriptの確認を行い、本番用のアプリをビルドします。

エラーが表示された場合は内容を確認して修正し、もう一度コマンドを実行します。
開発サーバーで画面が表示されることと、lint・buildが成功することを確認してから作業を完了します。

------------------------------------------
7. インストール後の作業の流れ
------------------------------------------

1. ターミナルで「app」フォルダーに移動する。
2. npm installを実行し、エラーなく完了したことを確認する。
3. package.jsonに追加したライブラリが記録されていることを確認する。
4. 必要な機能を決め、ソースコードからライブラリを読み込んで実装する。
5. npm run devでアプリを起動し、ブラウザーで機能を確認する。
6. npm run lintとnpm run buildを実行し、エラーがないことを確認する。

インストールは、機能を使うための準備です。
実際にアプリで使うには、必要なコードの追加と動作確認が必要です。
